SHIP-728 · Mobile retrospective features · design for review

Retrospectives › Features on a phone

Retrospectives › Features is a table with one row per Feature: its state, how many retros, a count for each of the four categories, how many points are left to decide, the Decided bar, action items and the last retro. Stories and bugs with no Feature sit in their own group. Each row opens that item's retro page (SHIP-729). At 900px and below this design keeps every number and changes how they fit. Each row becomes a short block in one list: key, state and date; the title; the four counts, what's left to decide and the Decided bar; then retros and action items. A legend names the colours once. The toolbar is one row: the Show filter, plus a Search button that opens the field in the same row. From 600 to 900px (tablets) the page stays the desktop table, at touch sizes.

Proposed acceptance criteria for SHIP-728

With the decisions as settled on 7 Nov. They go on SHIP-728.

  1. At 390 × 844 and 768 × 1024, in both themes, Retrospectives › Features has no page-level sideways scroll with any filter, with a search open, or with no rows. Above 900px nothing changes.
  2. Under 600px the toolbar is one row: Show (All | To decide | No Feature retro yet) and Search. Search turns the row into a 16px search field with Cancel; Cancel clears the search. Show and the search stay in the address as show and q. Nothing on the page sticks.
  3. Under 600px each Feature, and each story or bug with no Feature, is one row in a single list. The whole row opens the item's retro page and is at least 32px tall. It shows the type, key, state, last retro date, title, the “No Feature retro yet” chip when it applies, the four category counts in the fixed order, “n to decide” when there is something to decide, the Decided bar (or “nothing to decide”), and the number of retros and action items.
  4. The list's head shows “n Features with retros” and a legend with the four categories' colours and names in the fixed order.
  5. Stories and bugs with no Feature appear under their own heading in the same list and are filtered by Show and the search, as on desktop.
  6. A search with no match says “No Feature matches …” and offers Clear search. Under To decide with nothing to decide, the list says “Nothing left to decide.”
  7. From 600 to 900px the page is the desktop table and toolbar: Show buttons and rows at least 32px, a 16px search box, category heads on up to two lines, the Feature column pinned, and the columns that don't fit scrolling sideways inside the table's box only. The whole row opens the item's retro page. The phone list and Search button appear only under 600px.
  8. “No Feature retro yet” needs no hover to understand. Hover-only tooltips are not relied on.
  9. No new analytics events. screen.viewed for this page and for the item retro page carry viewport (SHIP-805 rule 16).
